Thesis at a glanceAbstract

Firms scale AI when their organisational maturity, relative to the fixed cost of scaling, is high enough for the value of the use case at their size.

Using AI is not the same as gaining value from it. The thesis argues this is not mainly a technology problem. It is a problem of organisational maturity, economics and management decisions, and it can be diagnosed.

How this is calculated

Required maturity c̄ = (T / A − θ) / γ, with A = exp(−1.105 + 0.215·ln L + 1.176·z), T = 3.30, θ = 0.3, γ = 1 (calibrated, thesis Ch. 6.4). z = 0 (median), 0.674 (top 25 %), 1.28 (top 10 %). Maturity c = (mean level − 1) / 4; weakest link c_min = (lowest level − 1) / 4. A 30 % lower fixed cost scales T by √0.7.

Decision rules: value pool below 1 % → discontinue · c̄ above 1 → redesign or share · level 1 in D2, D3 or D5 → build first · scale if c ≥ c̄ + 0.10, c_min ≥ c̄ and value pool ≥ 2 %.

Caveat: the 0.10 margin and the pool thresholds are working conventions for this tool. Thresholds are indicative and depend on one survey figure (22 % production use).
